SOLUTION RETENUE (CONFORME AU CAHIER DES CHARGES)
──────────────────────────────────────────────────────────────────────────────────

Après analyse, j'ai choisi de rester 100% conforme aux spécifications du cahier des
charges en utilisant uniquement un CNN baseline renforcé (sans Transfer Learning).
Voici pourquoi et comment :

1️⃣ ARCHITECTURE CNN — Conforme aux exigences
   ✓ Input : 128×128×3 (images IRM/CT normalisées)
   ✓ Output : 5 classes Softmax (stades 0 à IV)
   ✓ Modèle : Sequential CNN avec 4 blocs de convolution
   ✓ Activation : ReLU + BatchNormalization
   ✓ Couches finales : Dense(128) → Dense(5, Softmax)

   Justification : Le cahier des charges demande "CNN 2D baseline" avec Conv32→Conv64→
   Dense128→Dense5. On ajoute un bloc Conv128 supplémentaire pour compenser le petit
   dataset (~2870 images) sans passer par du Transfer Learning.

2️⃣ AUGMENTATION DE DONNÉES — Renforcée mais conforme
   ✓ Rotations : ±25° (spec : "rotations aléatoires")
   ✓ Flips : horizontal et vertical (spec : "flips horizontaux/verticaux")
   ✓ Zoom : ±15% (spec : "variations de zoom pour simuler différentes résolutions")
   ✓ Bonus : luminosité, décalages, cisaillement (imite variations capteur IRM)

3️⃣ LOSS FUNCTION — Focal Loss + Weighted Cross-Entropy
   ✓ Focal Loss(gamma=2.0) pour les classes difficiles/minoritaires
   ✓ Class weights pour compenser le déséquilibre (stage_4 < stage_0)
   ✓ Conforme à la spec : "gestion avancée du déséquilibre des classes"

4️⃣ MÉTRIQUES CLINIQUES — Comme demandé
   ✓ Accuracy globale
   ✓ Sensibilité (Recall) macro : cible > 95% (minimise faux négatifs)
   ✓ F2-Score (privilégie le rappel)
   ✓ ROC-AUC par stade (discrimination entre classes)

5️⃣ XAI — Grad-CAM obligatoire
   ✓ Génère des cartes de chaleur montrant les zones diagnostiques
   ✓ Indispensable pour la validation médicale
   ✓ Intégré à l'API et au Dashboard

6️⃣ DÉTECTION D'ANOMALIES — Auto-encodeur
   ✓ Entraîné sur images saines (stage_0 uniquement)
   ✓ Calcule l'erreur de reconstruction (MSE)
   ✓ Seuil : 95e percentile
   ✓ Alerte si anomalie détectée (cas atypique)

7️⃣ DÉPLOIEMENT — FastAPI + Streamlit + Docker
   ✓ API asynchrone pour requêtes simultanées
   ✓ Dashboard Web pour upload d'images et visualisation
   ✓ Conteneurisation Docker pour reproductibilité
